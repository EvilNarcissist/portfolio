# Портфолио

Сайт на Vite без фреймворков: HTML, CSS и немного JavaScript.

## Команды

```bash
npm install      # один раз
npm run dev      # локальный сервер, http://localhost:5173
npm run build    # сборка в папку dist
npm run preview  # посмотреть собранную версию
```

## Структура

- `index.html`: шаблон страницы. Личных текстов в нём нет, только подстановки вида `{{name}}`
- `content.json`: ваши данные: имя, тексты, проекты, опыт, email, соцсети. В git не попадает
- `content.example.json`: пример структуры с заглушками, он лежит в репозитории
- `vite.config.js`: подставляет данные в шаблон и рисует иконку вкладки из инициалов
- `src/styles.css`: палитра в `:root`, шрифты, анимации
- `src/main.js`: загрузка, меню, аккордеоны, превью проектов, эффект букв в имени
- `src/motion.js`: движение при прокрутке (Lenis и GSAP ScrollTrigger)
- `src/models.js`: каркасные 3D-модели в блоке услуг (свой рендер на canvas, без 3D-библиотек)

## Личные данные

Всё, что про вас, редактируется в `content.json`. Если файла нет, сборка берёт `content.example.json`.

На GitHub файл собирается из секрета `SITE_CONTENT`: Settings → Secrets and variables → Actions → New repository secret. В значение вставьте целиком содержимое `content.json`. Если изменили данные, обновите секрет и запустите Actions → Deploy to GitHub Pages → Run workflow.

У проекта можно показать ролик: положите файл в `public/media/` и укажите `video` и `poster` (пути вида `/media/файл`). Ролик запускается без звука при раскрытии карточки (кроме режима «уменьшить движение»). Вторая ссылка задаётся полями `link2` и `linkLabel2`.

У проекта можно задать `link` (адрес, начинающийся с https://) и `linkLabel` (подпись). Пустая ссылка не показывается.

Если список `projects` или `experience` пустой (`[]`), соответствующий блок вместе со ссылками в меню не показывается. Пустая строка `aboutNote` скрывает подпись под абзацем «Обо мне».

Что видно на самом сайте, видно всем (в том числе в исходном коде страницы). Секрет прячет данные только из репозитория.

## Что делает страница

- Имя в hero: буквы становятся жирнее рядом с курсором (только с мышью).
- Проекты и услуги раскрываются по клику. С мышью при наведении на проект рядом с курсором появляется превью.
- Абзац в «Обо мне» загорается по словам при прокрутке.
- Скролл плавный, с инерцией (Lenis). Якорные ссылки и меню едут к разделам, а не прыгают.
- Сверху тонкая полоса показывает, сколько страницы пройдено. Шапка прячется при прокрутке вниз и возвращается вверх.
- Hero: при прокрутке буквы имени разлетаются в стороны, фон с кодом отстаёт.
- Заголовки выезжают по словам. У каждого блока своё появление: проекты открываются «шторкой», услуги въезжают справа, в опыте растёт линия и набегают годы.
- «Контакты» выезжают поверх «Опыта» как лист, а тот уходит вглубь. Если остановиться рядом с началом блока, страница мягко притягивается к нему.
- Списки слегка наклоняются по скорости прокрутки.
- «Обо мне»: абзац закрепляется на экране, слова загораются строго по одному в порядке чтения, затем появляется подпись.
- Между разделами две крупные строки едут навстречу друг другу. Панель «Чем занимаюсь» разворачивается на всю ширину.
- Бегущая строка ускоряется при прокрутке и разворачивается, когда вы листаете вверх.
- В блоке услуг каркасная 3D-модель вращается от прокрутки; у каждой услуги своя фигура (куб в кубе, тор, икосаэдр).
- Кнопки слегка тянутся к курсору.
- Содержимое раскрытой строки появляется по очереди.
- При включённом `prefers-reduced-motion` эти эффекты отключаются.

## Публикация

После `npm run build` содержимое папки `dist` можно загрузить на Netlify, Vercel, Cloudflare Pages или GitHub Pages.
